# 🎬 Movie Recommender System

A content-based movie recommendation web app built with **Python** and **Streamlit**. Pick a movie from the dropdown and get 5 similar movies instantly, complete with posters fetched live from the **TMDB API**.

---

## Features

-  Search and select from **10,000 movies**
-  Get **5 similar movie recommendations** with one click
-  Live movie posters via the TMDB API
-  Interactive poster carousel (custom Streamlit component built with Svelte)
-  Fast results using precomputed similarity scores

---

##  How It Works

This is a **content-based filtering** recommender. It recommends movies whose content is most similar to the one you select.

1. **Load data**: 10,000 movies from `dataset.csv` (title, genre, overview, rating, etc.)
2. **Feature selection**: keep `id`, `title`, `overview`, and `genre`
3. **Create tags**: combine `overview` and `genre` into a single `tags` column
4. **Vectorize**: convert the tags into vectors with `CountVectorizer` (top 10,000 features, English stop words removed)
5. **Compute similarity**: calculate **cosine similarity** between every pair of movies
6. **Recommend**: for the selected movie, sort by similarity score and return the top 5 closest matches
7. **Display**: fetch posters from TMDB and show the results in Streamlit
